# RefleXion Medical

> RefleXion Medical is a privately held therapeutic oncology company in Hayward, California, founded in 2009 by Sam Mazin and Akshay Nanduri. It builds the RefleXion X1 radiotherapy platform and SCINTIX biology-guided radiotherapy, which uses onboard PET detectors to sense emissions from an injected radiopharmaceutical and autonomously direct external-beam radiotherapy with sub-second latency. RefleXion is a medical device manufacturer, not a software vendor: it publishes no developer portal, no API documentation, no SDKs and no machine-readable API contract.
